# 역사 인터뷰룸

역사 속 인물과 대화형 AI 인터뷰를 하며 역사적 사실을 파악하는 교수학습용 웹앱입니다.

- **학습 목표**: 역사 속 인물과의 대화형 인공지능 인터뷰를 통해 인물과의 대화로 역사적 사실을 파악한다.
- **대상**: 초등 고학년 ~ 중학생 (사회·역사)
- **등장 인물**: 세종대왕, 이순신, 정약용, 유관순
- **예상 활동 시간**: 15~25분

## 활동 흐름

1. **인터뷰** — 인물마다 질문 6개. 질문 버튼을 누르거나 직접 질문을 입력하면 인물이 답하고, 답 속 핵심 사실이 '취재 수첩'에 기록됩니다.
2. **팩트체크** — 기사 문장 5개가 사실인지 아닌지 판단합니다. 틀리면 근거와 함께 해설이 나옵니다.
3. **연표 완성** — 네 인물을 모두 취재하면 사건 7개를 시대 순으로 배열합니다.
4. **최종 보고서** — 인물별 점수, 별 개수, 기자 등급(수습 기자 → 역사 전문 기자)을 확인합니다.

## 점수

| 항목 | 점수 |
|---|---|
| 사실 수집 | 개당 10점 (인물당 최대 60점) |
| 직접 만든 질문 보너스 | 개당 5점 (인물당 최대 30점) |
| 팩트체크 | 문항당 20점 (인물당 최대 100점) |
| 연표 | 칸당 10점 + 완벽 보너스 30점 |
| **만점** | **860점** |

## AI 대화 방식

GitHub Pages는 서버가 없는 정적 호스팅이라 외부 AI 서비스를 부를 수 없습니다. 그래서 인물별 역사 기록을 바탕으로 한 **대화 엔진을 페이지 안에 넣었습니다.** 학생이 직접 쓴 질문의 핵심어를 분석해 알맞은 답을 고르고, 기록에 없는 질문에는 인물의 말투로 다른 질문을 권합니다.

- API 키, 로그인, 개인정보 입력이 필요 없습니다.
- 답변 내용이 미리 검토된 사실이라 AI가 사실과 다른 말을 지어낼 위험이 없습니다.
- 화면에 "역사 기록을 바탕으로 재현한 AI 캐릭터"라는 안내를 표시합니다.

## GitHub Pages 배포 방법

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name 예: `history-interview` → **Public** 선택 → **Create repository**
3. 저장소 화면에서 **uploading an existing file** 클릭 → `index.html`, `README.md`, `PROMPT.md` 끌어다 놓기 → **Commit changes**
4. **Settings** → 왼쪽 **Pages**
5. Source: **Deploy from a branch** / Branch: **main**, 폴더 **/(root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   `https://<GitHub아이디>.github.io/history-interview/`

## 파일 구성

- `index.html` — 웹앱 전체 (이 파일 하나로 동작)
- `README.md` — 이 안내 문서
- `PROMPT.md` — 제작에 사용한 프롬프트 기록 (점검·일지용, 지우지 마세요)

진행 기록은 학생 기기의 브라우저에 저장되며, 홈 화면의 "처음부터 다시 하기"로 지울 수 있습니다.
